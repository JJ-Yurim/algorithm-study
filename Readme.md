## D. 풀이 접근 및 복잡도

아래 복잡도는 현재 코드를 읽어 정리한 분석입니다. `n`은 원소·문자 개수, `k`는 선택된 원소 수, `r`·`c`는 행·열 개수, `t`는 반복 횟수입니다.

| 문제                      | 처리 흐름                        | 시간           | 결과 공간                 |
| ------------------------- | -------------------------------- | -------------- | ------------------------- |
| 나누어 떨어지는 숫자 배열 | 순회·조건 선택 → 정렬            | O(n + k log k) | O(k), 빈 결과는 상수 공간 |
| 제일 작은 수 제거하기     | 최솟값 계산 → 제외한 리스트 생성 | O(n)           | O(n)                      |
| 콜라츠 추측               | 홀짝 계산 반복, 최대 500회 제한  | O(t), t ≤ 500  | O(1)                      |
| 핸드폰 번호 가리기        | 마스킹 문자열과 끝 4자리 결합    | O(n)           | O(n)                      |
| 행렬의 덧셈               | 각 행·열의 같은 위치 더하기      | O(r × c)       | O(r × c)                  |

반복 횟수와 기본 연산을 기준으로 한 분석이며, 매우 큰 정수의 비트 연산 비용은 별도로 다루지 않습니다.

## E. 핵심 학습 내용

### 1. 리스트와 정렬

결과의 정렬 순서를 문제에서 요구하는지 확인합니다. `sort()`는 원본 리스트를 바꾸고 `None`을 반환하며, `sorted()`는 새 리스트를 반환합니다.

### 2. 조건식과 반복 종료

홀짝 판별에는 `%`, 정수 나눗셈에는 `//`를 사용합니다. 반복 조건의 방향, 계산식 누락, 횟수 제한과 경계값을 따로 확인합니다.

### 3. 문자열과 2차원 배열

문자열은 직접 수정하기보다 새 문자열을 구성합니다. 행렬에서는 전체 행 개수와 현재 행의 열 개수를 구분합니다.

## F. 생성형 AI 활용

풀이 파일에 설명형 학습 메모가 있지만 작성 도구나 AI 사용 이력을 확인할 수 있는 별도 기록은 없습니다. 따라서 특정 풀이가 AI로 작성되었다고 표시하지 않습니다.

학습 보조 도구를 사용할 경우에는 코드의 조건·복잡도·예외를 직접 설명하고 예제로 검증할 수 있는지를 기준으로 삼습니다.

## G. 실행 방법

저장소를 내려받은 뒤 Python 3 환경에서 개별 파일을 실행합니다.

```powershell
python "programmers/level1/행렬의_덧셈.py"
python "programmers/level1/핸드폰_번호_가리기.py"
```

각 파일 하단의 예제 입력을 사용해 결과를 출력합니다. 별도 입력 프롬프트는 없으므로 다른 사례를 확인하려면 파일의 예제 값을 바꾸거나 `solution(...)`을 호출합니다.

현재 하단 예제를 기준으로 행렬의 덧셈은 `[[4, 6], [7, 9]]`, 핸드폰 번호 가리기는 `*****8888`이 예상됩니다. 예상값 설명이며 이번 README 편집에서 온라인 채점을 수행한 결과는 아닙니다.
